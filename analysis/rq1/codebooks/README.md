# RQ1 codebooks and annotations

This folder contains the reviewed PTM IDs, reuse rules, and manual annotations used in RQ1.

| File | Contents |
| --- | --- |
| [PTM_id_codebook.xlsx](PTM_id_codebook.xlsx) | PTM IDs and naming components. |
| [reuse_codebook.xlsx](reuse_codebook.xlsx) | Import origins and eligible PTM-use calls. |
| [real_reuse_annotations.xlsx](real_reuse_annotations.xlsx) | Final reuse labels and both annotation rounds after discussion. |
| [fp_codebook.xlsx](fp_codebook.xlsx) | Non-reuse categories and evidence examples. |
| [binding_patterns.xlsx](binding_patterns.xlsx) | Pattern definitions, case codes, and summaries. |
| [binding_paths.xlsx](binding_paths.xlsx) | Ordered evidence links for confirmed reuse cases. |
| [manual_binding_locality.xlsx](manual_binding_locality.xlsx) | File and hop counts, procedure crossings, and locality labels. |

See the [real reuse guideline](real_reuse_annotation_guideline.md) for reuse, path, and locality annotation, and the [binding pattern guideline](binding_patterns_guideline.md) for assigning pattern codes.

`benchmark_case_001`–`328` identify the reuse-classification cases. `binding_case_001`–`093` identify the confirmed reuse cases across the binding workbooks. The `binding_case_id` column in [benchmark.xlsx](../evaluation/classification/benchmark.xlsx) connects the two.
