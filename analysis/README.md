# Data analysis

This folder contains the scripts, inputs, annotations, and results for our research questions.

- **RQ1 — Reuse detection:** [Codebooks and guidelines](rq1/codebooks/README.md), plus [classification and reachability evaluation](rq1/evaluation/README.md) against the baselines.
- **RQ2a — PTM integration:** [Access interfaces, interface mixing, and binding locality](rq2a/README.md).
- **RQ2b — PTM evolution:** [PTM changes, their visibility in model-ID counts, and integration changes with stable counts](rq2b/README.md), including change types and breadth.

Each guide lists the inputs, commands, and outputs. RQ1 scoring uses the included workbooks and CSVs. RQ2 analyses use the single database described in the [database guide](../database/README.md).
